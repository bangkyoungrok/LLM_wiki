# 파일 첨부 오류 분석 결과

## 1. 핵심 요약
- 파일 첨부 서비스는 허용된 35종의 형식만 업로드할 수 있으며, 최대 5개 파일, 파일당 50.0 MB, 업로드 후 90일 보관 제한이 있음 [p.1]
- .crx(브라우저 확장) 및 .exe(설치 프로그램)는 허용 형식 목록에 포함되지 않아 업로드가 차단되며, 이는 실행 가능 파일에 대한 보안 정책 적용으로 판단됨 [p.2]
- 파일 선택 후 "메시지에 첨부" 버튼을 누르지 않으면 실제 전송 단계가 완료되지 않아 첨부 상태로 취급되지 않음 [p.2]
- 허용되지 않는 형식의 파일이 필요하다면, 압축(.zip)이나 문서화(.pdf/.txt) 형태로 변환하여 첨부하는 것이 대안임 [p.2]

## 2. 주요 개념 및 정의
- **업로드 영역**: "여기에 파일을 끌어다 놓으세요 또는 클릭하여 내 PC에서 파일을 선택하세요"라고 안내되는 파일 선택 구간 [p.1]
- **선택된 파일**: 업로드 영역에서 선택되었으나 전송 버튼 미클릭 상태의 파일 (예: NASCA_GUIDE.txt) [p.1]
- **허용 형식**: 시스템이 허용하는 35종의 파일 확장자 목록 (구체적 목록은 원문에 명시되지 않음) [p.1]
- **보안 차단 대상**: .crx(DRM 관련 확장), .exe(설치 프로그램) 등 실행 가능 파일. 악성코드 및 무단 실행 위험 방지 목적 [p.2]

## 3. 핵심 지식
### 3.1 규정 및 판단 기준
- 허용 형식: 총 35종 (TXT는 포함, CRX/EXE는 미포함) [p.1, p.2]
- 최대 첨부 개수: 5개 [p.1]
- 파일당 크기 제한: 50.0 MB [p.1]
- 보관 기간: 업로드 후 90일 [p.1]
- 전송 조건: 파일 선택 후 "[메시지에 첨부]" 버튼 클릭 필수 [p.1]

### 3.2 업무 절차
1. 업로드 영역에 파일 드래그 앤 드롭 또는 클릭하여 파일 선택 [p.1]
2. 선택된 파일이 허용 형식인지 확인 (오류 메시지 확인) [p.1, p.2]
3. "[메시지에 첨부]" 버튼 클릭하여 첨부 적용 [p.1, p.2]

### 3.3 개념·데이터 간 관계
- 파일 선택 ≠ 첨부 완료: 파일이 목록에 표시되어도 전송 버튼 미클릭 시 "선택된 파일" 상태이며 실제 첨부 상태가 아님 [p.2]
- 형식 오류 발생 시점: 파일 선택 즉시 허용 형식 여부를 검증하여 오류 메시지 표시 [p.1]
- 보안 정책과 형식 제한의 관계: .crx, .exe 등은 실행 위험성으로 인해 보안 정책상 허용 형식에서 제외 [p.2]

## 4. 적용 상황
- 파일 첨부 시 "지원하지 않는 형식입니다" 오류 메시지 발생 원인 파악
- .crx 또는 .exe 파일 첨부가 필요한 경우의 대안(압축/문서화) 결정
- 첨부 서비스의 크기, 개수, 보관 기간 제한 기준 확인
- 파일이 선택되었으나 메시지에 반영되지 않는 현상 해결 (전송 버튼 클릭 여부 확인)

## 5. 예외 및 주의사항
- "NASCA_GUIDE.txt"는 허용 형식(TXT)이지만, "[메시지에 첨부]" 버튼을 누르지 않으면 실제 첨부가 되지 않음 [p.2]
- .crx 및 .exe 파일은 보안 정책상 정상적인 차단으로 보이며, 우회 없이 형식 변환(압축/문서화)이 필요함 [p.2]
- 35종 허용 형식의 구체적 목록은 원문에 미포함되어, 허용 여부는 시스템 오류 메시지나 별도 안내를 통해 확인 필요 [p.1]

## 6. 확인 필요 사항
- 허용되는 35종 파일 형식의 구체적인 목록이 원문에 제시되지 않음 [p.1]
- NASCA_GUIDE.txt 파일의 실제 내용 분석은 파일이 전송(첨부)된 후에만 가능하며, 본 문서에는 내용 미포함 [p.2]
- "NASCA Server DRM_1.5.crx" 및 "BANDIZIP-SETUP-STD-X64.exe" 파일의 원본 소스나 대체 파일 확보 여부 불명 [p.2]
