# BQMS IT User Manual: Bidding Registration (with IRP Interface)

## 1. 핵심 요약
- BQMS 입찰 등록은 계약 유형, 평가 방법, 선정 방식 등 기본 정보 입력을 시작으로, 품목 및 벤더 관리, 일정(Timeline) 및 평가(Evaluation) 설정, 최종 공고 송신과 승인 요청까지 이루어지는 단계적 과정임.
- 내부(SEC)용 및 외부(벤더)용 파일은 각각 최대 200MB 제한이 있으며, 법률 시스템 연동(Legal System I/F)을 'Yes'로 설정한 후 취소할 수 없음.
- 평가 시트(Evaluation Sheet)는 계약 유형에 따라 LV1~LV4 계층 구조로 구성되며, 항목별 가중치(Weight)와 평가 방식(Mode)을 설정해야 함.
- 입찰 공고는 최소 2명의 평가관(Evaluator) 선정을 전제로 하며, 'Notification Vendor'를 통해 벤더에게 공지하고 'Submit'을 통해 승인 요청을 진행함.
- IRP 연동 시 IRP 코드가 표시되며, 승인 후 지정 기간 내에 입찰자가 문서를 제출하고 매니저가 열람하는 구조임.

## 2. 주요 개념 및 정의
- **Contract Types**: Goods Contract, Service Agreement, Goods Contract + Service Agreement (Hybrid), Sale Agreement [p.4]
- **Evaluation Methods**: Price Evaluation, Technical Evaluation, Price + Technical Evaluation [p.5]
- **Vendor Selection Count**: Singular(1개사 선정), Multiple(2개사 이상 선정) [p.5]
- **Evaluation Sheet**: 평가 항목, 가중치, 평가 방식 등 기준을 정의하는 시트로, 계약 유형 기반 계층 구조(LV1~LV4)를 가짐 [p.13, p.15]
- **Bidding Announcement**: Basic Information, Items and Vendors, Timeline, Evaluation, Evaluator 탭으로 구성되는 입찰 공고 기능 [p.11, p.16]

## 3. 핵심 지식
### 3.1 규정 및 판단 기준
- **파일 업로드 제한**: Internal(SEC) 및 External(Vendor) 파일은 각각 최대 200MB 제한 [p.8, p.9]
- **품목 등록 제한**: Item Code가 100개 이상일 경우 Excel Upload 기능 사용 필수 [p.11]
- **수량(MAX Qty) 제한**: Code Qty × Vendor Qty <= 4,000 (4K) [p.11]
- **외환 기준일**: 해당 월의 1일 기준 [p.3]
- **평가관 선정**: 2명 이상의 Evaluator 선택 필수 [p.16]
- **평가 결과 입력**: 'Y' 선택 시 평가관 직접 입력, 'N' 선택 시 입찰 매니저가 결과 요청 [p.16]
- **입찰 평가 예시**: Unit_Price, Credit Rank, Man-Power, Tech/Experience, Tech/License 항목 모두 Weight 20, Required Yes로 설정된 사례 존재 [p.15]

### 3.2 업무 절차
1. **Bidding Info Entry**:
   - 개요, 계약 유형/형태, 예상 금액 확인, 계약 기간, 법률 시스템 I/F(Yes/No), IRP 코드 확인 [p.3, p.4]
   - 평가 방법, 벤더 선정 수량(단수/복수), 목적/산출물 요약, 조항(Dictate terms) 입력 [p.5, p.6, p.7]
   - 내부/외부 파일 업로드, Site Code 및 매니저 검색 후 'Save' 및 'Next' 클릭 [p.8, p.9, p.10]
2. **Items and Vendors**:
   - Bid Items(품목) 및 Vendor 추가/삭제 [p.11]
   - 등록 완료 시 BOMS를 통해 벤더에게 이메일 자동 발송 [p.11]
3. **Timeline 설정**:
   - Pre-bid Meeting Date, Question Deadline, Submission Period, Evaluation Period, Award Date 설정 [p.12]
4. **Evaluation 설정**:
   - 기존 Sheet 사용: Contract Type 기반 Sheet 선택 후 항목 관리(Template, Previous, Add, Delete) [p.13]
   - 신규 Sheet 등록: 'Add' 클릭 → Criteria, Weight, Mode of Evaluation 입력 [p.14]
   - 평가 시트 임포트: 'Template' 버튼 → 'OK' → 임포트 확인 → 'Next' [p.15]
5. **Evaluator 관리**:
   - 평가 유형 선택, 'Add' 버튼으로 평가관 추가/삭제, 'Save' 확정 [p.16]
6. **공고 송신 및 승인**:
   - 'Basic Information' 탭으로 이동 → 데이터 확인 → 'Notification Vendor' 클릭 → 'Confirm' [p.17]
   - 'Submit' 클릭 → 'Approval Requested.' 메시지 확인 → 입찰 공고 목록 화면 전환 [p.18, p.19]

### 3.3 개념·데이터 간 관계
- **데이터 흐름**: 'Bidding Information' 데이터는 'Next' 클릭 시 'Bidding Items and Vendors'로 전이됨 [p.10]
- **IRP 연동**: 벤더 선정 요청 시 IRP 코드가 선택되며, 입찰 목록에 IRP 연간 계획 관련 Project code가 표시됨 [p.3, p.19]
- **파일 분류**: Internal 파일은 SEC 내부 사용, External 파일은 벤더용 구분 [p.8]
- **승인 후 절차**: Bidding Announcement 승인(Approved) → 입찰자 공고 확인 및 지정 기간 내 문서 제출 → 매니저 열람 [p.19]

## 4. 적용 상황
- BQMS에서 신규 입찰 등록을 수행할 때 필요한 입력 항목과 순서를 확인해야 할 때
- 평가 시트(Evaluation Sheet)의 가중치, 평가 방식 설정이나 신규 시트 생성이 필요할 때
- 입찰 공고 송신 전 체크리스트(파일 용량, 품목 수, 평가관 수 등)를 점검해야 할 때
- 법률 시스템 연동 여부 설정 및 그로 인한 변경 불가 상황을 파악해야 할 때
- IRP 코드와 입찰 프로젝트 간의 연관성을 이해해야 할 때

## 5. 예외 및 주의사항
- **법률 시스템 변경 불가**: 정보 전송 후 Legal System I/F를 'Yes'에서 'No'로 변경하는 것은 불가능함 [p.4]
- **테스트 데이터 주의**: 문서 내 날짜는 테스트 목적이며, 실무에서는 Bidding 및 Evaluation 기간이 2~3일 미만인 경우 비추천 [p.4, p.12]
- **Cancel 버튼 영향**: 'Cancel' 클릭 시 입력 데이터가 삭제되고 페이지가 읽기 전용(Read-only) 모드로 전환됨 [p.10]
- **평가 시트 변경 경고**: 기존 값이 있는 상태에서 시트를 변경하면 "Existing value disappear..." 경고 창이 표시됨 [p.15]
- **승인 경로 부재**: 승인 경로가 없는 경우 공급업체에게 공지(Notification)를 보내야 함 [p.17]
- **대용량 데이터 처리**: Item Code 100개 초과 시 수동 입력 대신 Excel Upload 템플릿 사용 권장 [p.11]

## 6. 확인 필요 사항
- **파일 제한 불일치**: [p.8]에는 최대 200MB만 명시되어 있으나, [p.9]에는 "999 files and 200.0 MB"로 파일 개수 제한(999개)이 추가로 언급됨. 파일 개수 제한 적용 여부 확인 필요 [p.8, p.9]
- **버튼 번호 오류**: [p.10] 텍스트 설명에서 Delete, Cancel, List 버튼이 모두 "3단계"로 라벨링되어 있으나, 화면상 번호는 각각 3, 4, 5번임. 실제 운영 시 버튼 번호 기준인지 텍스트 단계 기준인지 확인 필요 [p.10]
