# 규칙

질문에서 한 값을 조회할 때 **여러 테이블에 같은 컬럼/값**이 존재할 수 있다 (예: 법인코드=TI_GRPF900 마스터 vs TI_GRPB_DE_PAYMENT_REPORT 거래 테이블). 이때 후보 테이블을 **`table_type`(문서 frontmatter) 순서**로 검토해, 먼저 맞는 유형을 우선 사용한다.

## 선택 순서

```
종합리포트 > 리포트 > 마스터 > 인터페이스 > 기준정보 > 기타(table_type 없음)
```

(출처: add_info/rule.csv "T2S 테이블 선택·전역")

## 의미

- **종합리포트/리포트**: 여러 테이블이 결합된 최종 테이블(TI_BQMS840, TI_GRPF_EO_REPORT 등). 질문에 맞는 값이 하나면 여기서 해결되는 경우가 많아 **우선**.
- **마스터/인터페이스/기준정보**: 세부·원본 테이블. 종합/리포트 테이블에 컬럼이 없거나, 원본의 세부 값(이력, I/F 원본)이 필요할 때.
- **기타**: `table_type` 필드가 없는 테이블은 순서상 마지막.
- **시나리오** 유형(TR_SSA00/TR_SBQ00 등)은 시나리오 **추출 결과 저장소**라 T2S 조회 대상에서 제외 (선택 순서에 없음).

## 적용 예

- "입찰 건의 업체·금액" → `TI_BQMS840`(종합리포트) 우선, 필요 시 `TI_BQMS004_INFA_BD`(인터페이스) 원본.
- "법인코드 C430 명칭" → `TI_GRPF900`(기준정보) 또는 거래 테이블의 CMNM. 마스터/기준정보 수준이면 그 테이블 사용.

## 한계

- 유형이 같으면(예: 리포트 여러 개)는 질문과 **컬럼·업무 영역(business_area/business_detail) 일치도**로 고른다.
- 이 규칙은 **후보 좁히기**이지, 조인·행 수 제한·PII 규칙을 대체하지 않는다. 선택된 테이블에도 다른 t2s 규칙이 모두 적용된다.
