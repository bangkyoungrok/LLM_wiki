# 시나리오 분석 요약 (v2)

`plsql_slim_v2` 기준 23개 시나리오를 **변형 생성 중심**으로 재구성한 자료다.
각 리포트는 `1 사용 테이블 → 2 조건 인벤토리(+2.1 원본 추적) → 3 파생 컬럼 → 4 단계 필터(+4.1 공식 단계) → 5 변형(슬롯·조합·추가교체·제약) → 6 SQL 스켈레톤` 순이다.

## 1. 전체 개요

| 항목 | 값 |
|:--|:--|
| 시나리오 | 23건 |
| 사용 테이블(중복 제거) | 47개 |
| 탐지 단계 | 최소 1 / 최대 5 / 합계 67 |
| 변형 난이도 | 낮음 14 / 중간 8 / 높음 1 |
