# 개요

`add_info/procedure/`의 감사 시나리오 추출 스크립트 38건(.prc/.sql, SETADAMSUSER 프로시져)을 이식했다.
이 문서의 역할은 **T2S 예제(`t2s/examples/`)의 근거 원천**이다:

- 시나리오별 **감사 포인트**(무엇을 점검하는지)와 **참조 테이블**을 알려, 자연어 질문("들러리 견적은 어떻게 찾나?")을 실제 SQL로 바꿀 때 출발점이 된다.
- 아래 참조 테이블은 프로시져 본문에서 추출해 **번들(AIAGT 접근 범위) 안 테이블만 링크**했다. `*`은 범위 밖(링크 불가). `TMP*`는 프로시져 내부 PL/SQL 임시 테이블이라 제외했다.
- **참고**: 프로시져는 `TR_SSA00`(영업마케팅) / `TR_SBQ00`(BQMS) 시나리오 추출내역 테이블에 Delete/Insert 하는 **배치 로직**이다. T2S는 이 배치 SQL을 그대로 쓰는 게 아니라, 참조 테이블·감사 포인트를 근거로 **조회(SELECT) SQL**을 새로 만든다. (SELECT 전용 규칙)
- 상세 감사 로직(단계별 필터·조인)은 원본 `.prc`/`.SQL` 파일에 있다. 번들에 SQL 전문을 복제하지 않는다.
