# DP-005 간접 공급 경로 대사

- 묶음: **진위 판별** — 대사로 나온 초과가 진짜 초과인지, 기준·단위·표기 문제로 생긴 초과인지 가른다
- 관점: 공급 경로 — 중간 유통을 거친 공급을 더해도 초과인가
- 사고 유형: ⑦ 정책/시스템 통제 미흡 (보정 후에도 초과면 ④)
- 대상 범위: **대조** — 직전 결과를 다른 테이블과 맞대어 남길 건과 뺄 건을 가른다
- 설명: 회사 → 중간 유통(Dist'y) → 하위 거래선으로 가는 간접 공급분은 하위 거래선의 직접 공급 기록에 잡히지 않아, 그 거래선의 공급이 과소집계되고 초과처럼 보인다. 직전 결과의 초과 거래선 가운데 중간 유통을 거쳐 공급받는 거래선에 중간 유통의 남은 물량을 더해 다시 대사한다.
- 답하는 질문: 직전 결과의 초과 거래선에 중간 유통을 거친 공급을 더해도 지급이 공급을 넘는가
- 관련 패턴(참고): [P-104 참조 무결성 위반](okf/wiki/patterns/anomaly/P-104.md), [P-102 테이블간 조인 불일치](okf/wiki/patterns/anomaly/P-102.md)

## 고르는 때

보고서(누적 보고서와 부록 SQL)에서 아래 신호가 보이면 이 패턴을 후보로 둔다.

- 직전 결과의 초과 거래선 가운데 직접 공급이 지급에 비해 매우 작은 거래선이 있다
- 법인이 중간 유통을 거치는 판매 구조를 운영한다(보고서·도메인 문서에 2nd Tier, Dist'y 경유 언급)

## 고르지 않는 때

- 셀아웃 검증 내역 등에 공급처(중간 유통) 정보가 없다 → 확인 필요로 남긴다

## 추출 로직

1. 직전 결과의 초과 거래선마다 셀아웃 검증 정산 내역의 공급처 정보로 공급한 중간 유통을 특정한다. 없으면 「공급처 미확인」
2. 중간 유통 잔여 물량 = 중간 유통의 같은 제품 누적 공급 − 중간 유통 자체 지급수량 − 같은 중간 유통 아래 다른 거래선의 지급수량
3. 보정 공급량 = 거래선의 직접 누적 공급 + 배분된 중간 유통 잔여 물량
4. 판정 ① 해소 → 「간접 공급(별도 대사)」, 결과에서 뺀다 / ② 유지 → 「과다청구 후보」, 남긴다

## 정상 예외

질문에 「제외해 줘」로 넣는다.

- 중간 유통 물량을 법인 별도 시스템으로 관리하는 경우 — N-ERP 빌링 기준 공급이 과소집계된다. 법인 자료로 확인할 대상으로 표시한다

## 임계 조정

숫자를 새로 정하지 않는다. 기준은 시나리오 생성 에이전트가 데이터 분포를 보고 정한다.

- 같은 중간 유통 아래 초과 거래선이 여럿이면 잔여 물량을 지급 비율대로 나눠 배분한다(한 거래선에 몰아 주지 않는다)

## 멈춤 기준

- ② 가 특정 중간 유통 아래로 모이면 멈출 수 있다
- 공급처를 대부분 특정하지 못하면 「공급처 미확인」으로 정리하고 멈춘다

## 질문 단서

> 직전 결과의 초과 거래선 가운데 중간 유통을 거쳐 공급받는 거래선은, 그 중간 유통의 남은 셀인 물량을 지급 비율대로 더해 다시 비교하고, 그래도 셀아웃이 셀인을 넘는 건만 남겨 줘.

드릴다운 질문의 「이번 관점」 줄로 쓴다(원본 질의와 이전 관점 줄 뒤). 직전 결과에 맞춰 고쳐 쓰고, 함께 고른 패턴이 있으면 한 줄로 합친다. 물리명·패턴 번호는 쓰지 않는다.

## 대입 예시: 셀아웃 인센티브 과다지급

- 기준 시나리오: 셀아웃 인센티브 과다지급(영업 / 판매법인 / 매출차감, '23.上 등록). 거래선/SKU 기준 누적 셀인 < 셀아웃 인센티브 지급수량
- Risk 사례: ■■법인은 당사가 직공급하는 물량 外 중간 유통을 통한 간접 공급분(당사 → 중간 유통 → 2nd Tier 거래선)을 법인 별도 시스템(2nd Tier 별 셀스루·셀아웃 관리)으로 관리, 누적 셀인이 실제보다 과소집계
- 관련 테이블: `TI_GRPB_DE_SELLOUT`(셀아웃 검증 정산 내역), `TI_GRPB004B`(빌링)

## 확인 필요

- `TI_GRPB_DE_SELLOUT` 에 공급처(중간 유통) 정보가 있는지
