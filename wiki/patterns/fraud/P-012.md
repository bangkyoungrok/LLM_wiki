# P-012 보증 및 서비스 시스템 남용

- 위험 구분: **부정(고의)** — 일부러 규정·통제를 어기거나 숨긴 행위다. 예외 조건에 고의성 신호를 넣는다(`wiki/patterns/index.md` 2절).
- 설명: 보증 및 애프터세일스 서비스 시스템을 악용하여 불필요한 비용 발생 또는 서비스 혜택 유출. 반품 제품을 서비스 시스템에 등록하지 않아 보증 대상인 것처럼 잘못 처리하고, 무단 대리점에 판매된 보증 기간 만료 제품에 대해 CS 팀에 통보하지 않으며, 개인 기기를 위해 가짜 서비스 요청을 생성함
- ACFE: Customer Refund Fraud (Warranty Abuse, Service System Exploitation)
- COSO: CA-03-01 승인 통제, CA-03-02 검증·조정, CA-03-06 독립 검토
- 탐지 기법(SQL 형태, 원본 분류): 임계 초과 — 절대 임계 초과 `WHERE col > fixed_threshold`, 통계적 임계 초과 `WHERE ABS(col-avg)/std > 2`, 비율 임계 초과 `WHERE col_a/col_b > ratio`, 누적 임계 초과 `WHERE SUM(col) OVER (...) > limit`, 극단값 탐지 `WHERE col >= PERCENTILE(0.99)`, 범위 상한 초과 `WHERE col > logical_max`; 누락·부재 — 필수 필드 NULL `WHERE required_col IS NULL`, 검증 로그 부재 `LEFT JOIN audit WHERE id IS NULL`, 증빙 파일 부재 `WHERE attachment IS NULL`, 역조건 존재 `WHERE cancel='Y' AND amount > 0`
- SQL 대입: 도메인 없음

## 수법

- 반품 제품을 서비스 시스템에 등록하지 않아 보증 대상인 것처럼 잘못 처리
- 무단 대리점에 판매된 보증 기간 만료 제품에 대해 CS 팀에 통보하지 않음
- 개인 기기를 위해 가짜 서비스 요청 생성

## 탐지 방법

- 제품 반품 기록과 서비스 시스템 항목 조정
- 이전에 반품되었거나 무단 채널에 판매된 제품에 대한 보증 클레임 플래그
- 대리점 인증 상태를 서비스 클레임 기원과 교차 참조
- 제품 라인 및 대리점 네트워크별 보증 비용 트렌드 모니터링

## 질의 골격 (원본)

- SQL: `WHERE attachment IS NULL`
- SPARQL(참고, 이 환경에는 KG 가 없다): `?e a dpsc:MarketingEvent . OPTIONAL { ?e dpsp:hasEvidenceDocument ?doc } . FILTER(!BOUND(?doc))`

## OKF 대입 힌트 (자동 생성)

- 후보 도메인: 없음(OKF 도메인 11종에 해당 업무가 없다)
- 주의: 보증·서비스(애프터세일즈) 테이블이 OKF 도메인에 없다. 목차에서 찾지 못하면 만들지 않은 후보로 둔다.

## 조합 단서 (자동 생성)

- SQL 대입이 「도메인 없음」인 패턴이라 조합에 넣지 않는다.
