# P-002 사외펀드(Slush Fund) 조성

- 위험 구분: **부정(고의)** — 일부러 규정·통제를 어기거나 숨긴 행위다. 예외 조건에 고의성 신호를 넣는다(`wiki/patterns/index.md` 2절).
- 설명: 대리인과 공모하여 부풀려지거나 가짜 마케팅/프로모션 비용을 통해 사외펀드를 조성한 후, 무단 목적 또는 사적 이익을 위해 자금 이동. 가짜 Co-op 마케팅 또는 프로모션 이벤트를 생성하고 대리인에게 위조 문서를 제출하며, 구두 가격 약속 후 가짜 프로모션으로 비용 충당, 미사용 프로모션 예산을 향후 기간으로 이월(Rollover)함
- ACFE: Cash Disbursements Fraud (Slush Fund, Promotional Fund Manipulation)
- COSO: CA-03-01 승인 통제, CA-03-02 검증·조정, RA-01-03 위험 식별 프로세스
- 탐지 기법(SQL 형태, 원본 분류): 임계 초과 — 절대 임계 초과 `WHERE col > fixed_threshold`, 통계적 임계 초과 `WHERE ABS(col-avg)/std > 2`, 비율 임계 초과 `WHERE col_a/col_b > ratio`, 누적 임계 초과 `WHERE SUM(col) OVER (...) > limit`, 극단값 탐지 `WHERE col >= PERCENTILE(0.99)`, 범위 상한 초과 `WHERE col > logical_max`; 중복·동일인 — 식별자 중복 `GROUP BY id HAVING COUNT(*) > 1`, 연락처 중복 `GROUP BY acct_no HAVING COUNT(*) > 1`, 증빙 중복 `GROUP BY invoice_no HAVING COUNT(*) > 1`, 역할 중복 `WHERE requester = approver`, 교차 엔티티 일치 `WHERE a.col = b.col`, 완전 중복 `WHERE EXISTS (SELECT 1 FROM t2 ...)`; 추세·분포 — 지속 방향성 변화 `WHERE col > LAG(col) > LAG(col,2)`, 급증/급감 `WHERE ABS(col-LAG(col))/LAG(col) > 0.5`, 분포 편차 `GROUP BY grp HAVING COUNT > threshold`, 집중도 이상 `WHERE GINI(col) > 0.5`, 역추세 `WHERE CORR(col_a, col_b) < -0.5`
- SQL 대입: 가능

## 수법

- 가짜 Co-op 마케팅 또는 프로모션 이벤트 생성 및 대리인에게 위조 문서 제출 요청
- 대리인에게 구두 가격 지원 약속 후 비용 충당을 위해 가짜 프로모션 생성
- 예산 잉여를 사용하여 기프트카드, 전자제품 또는 기타 사적 물품 구매
- 미사용 프로모션 예산을 향후 기간으로 이월(Rollover)

## 탐지 방법

- 마케팅 이벤트 클레임을 독립적 증거(사진, 출석 기록, 벤더 배송 로그)와 교차 확인
- 검증할 수 없는 이벤트에 대해 반복적 지불을 받는 벤더 플래그
- 예산 사용 패턴 모니터링 — 특히 기간 말 급증
- 공식 문서화가 없는 구두 계약 기반 arrangement 감지
- 여러 직원으로부터의 동일한 벤더에 대한 영수증 패턴 분석

## 질의 골격 (원본)

- SQL: `{ SELECT (SUM(?a) AS ?total) WHERE { ?x dpsp:amount ?a } } FILTER(?total > ?limit)`
- SPARQL(참고, 이 환경에는 KG 가 없다): `?s dpsp:amount ?amt . { SELECT (SUM(?a) AS ?total) WHERE { ?x dpsp:amount ?a } } FILTER(?total > ?limit)`
