# P-013 생산 데이터 조작

- 위험 구분: **부정(고의)** — 일부러 규정·통제를 어기거나 숨긴 행위다. 예외 조건에 고의성 신호를 넣는다(`wiki/patterns/index.md` 2절).
- 설명: 제조 공정에서 생산량, 품질 검사, 폐기 데이터를 조작하여 생산 목표 달성, 불량률 은폐, 또는 부당 인센티브/비용 청구. 실제 생산량보다 높은 생산 수량을 시스템 입력하고, 불량품 양산 후 양품으로 분류하여 출고하며, 폐기 처리해야 할 제품을 시스템에서 누락시켜 재고 불일치를 생성하고 생산 라인 가동률 데이터를 위조하여 효율성 인센티브를 청구하며, 납품 품질 검사 보고서를 조작하여 불량 납품을 합격 처리함
- ACFE: Revenue Recognition Fraud (Fake Production Records), Inventory Fraud (Quality Data Manipulation)
- COSO: CA-03-02 검증·조정, CA-03-04 실적을행 비교, CA-03-05 책임 분리
- 탐지 기법(SQL 형태, 원본 분류): 값 불일치 — 필드간 값 불일치 `WHERE col_a != col_b`, 테이블간 조인 불일치 `JOIN ... WHERE a.col != b.col`, 논리적 관계 위반 `WHERE col_a < col_b (A≥B여야 함)`, 참조 무결성 위반 `LEFT JOIN ... WHERE ref IS NULL`; 임계 초과 — 절대 임계 초과 `WHERE col > fixed_threshold`, 통계적 임계 초과 `WHERE ABS(col-avg)/std > 2`, 비율 임계 초과 `WHERE col_a/col_b > ratio`, 누적 임계 초과 `WHERE SUM(col) OVER (...) > limit`, 극단값 탐지 `WHERE col >= PERCENTILE(0.99)`, 범위 상한 초과 `WHERE col > logical_max`; 추세·분포 — 지속 방향성 변화 `WHERE col > LAG(col) > LAG(col,2)`, 급증/급감 `WHERE ABS(col-LAG(col))/LAG(col) > 0.5`, 분포 편차 `GROUP BY grp HAVING COUNT > threshold`, 집중도 이상 `WHERE GINI(col) > 0.5`, 역추세 `WHERE CORR(col_a, col_b) < -0.5`
- SQL 대입: 도메인 없음

## 수법

- 실제 생산량보다 높은 생산 수량 시스템 입력 (실적 조작)
- 불량품 양산 후 양품으로 분류하여 출고 (품질 검사 우회)
- 폐기 처리해야 할 제품을 시스템에서 누락시켜 재고 불일치 생성
- 생산 라인 가동률 데이터 위조하여 효율성 인센티브 청구
- 납품 품질 검사 보고서 조작하여 불량 납품 합격 처리

## 탐지 방법

- 원자재 투입량 대비 완제품 출고량 수지 분석 (Input-Output 분석)
- 불량률 추세와 고객 반품/A/S 건수 상관관계 분석
- 폐기 기록과 폐기물 처리 업체 납품서 교차 검증
- 품질 검사 데이터의 통계적 이상치 감지 (특정 검사관/교대/시간대)
- 생산량과 전력/에너지 소비량 간 상관관계 모니터링

## 질의 골격 (원본)

- SQL: `WHERE ABS(col-avg)/std > 2`
- SPARQL(참고, 이 환경에는 KG 가 없다): `?s dpsp:amount ?amt . { SELECT (AVG(?a) AS ?avg) (STDDEV(?a) AS ?std) WHERE { ?x dpsp:amount ?a } } FILTER((ABS(?amt-?avg)/?std) > 2)`

## OKF 대입 힌트 (자동 생성)

- 후보 도메인: 없음(OKF 도메인 11종에 해당 업무가 없다)
- 주의: 생산·품질 테이블이 OKF 도메인에 없다. 목차에서 찾지 못하면 만들지 않은 후보로 둔다.

## 조합 단서 (자동 생성)

- SQL 대입이 「도메인 없음」인 패턴이라 조합에 넣지 않는다.
