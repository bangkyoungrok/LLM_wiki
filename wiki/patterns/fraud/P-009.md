# P-009 예산 편법 사용 및 크로스 차징

- 위험 구분: **부정(고의)** — 일부러 규정·통제를 어기거나 숨긴 행위다. 예외 조건에 고의성 신호를 넣는다(`wiki/patterns/index.md` 2절).
- 설명: 승인된 예산을 무단 목적으로 사용, 잘못된 비용 센터 또는 프로젝트에 비용 청구 포함. 프로젝트 A 예산 고갈 시 프로젝트 A 비용을 프로젝트 B에 청구하고, 남은 프로모션 이벤트 예산으로 개인 물품 구매를 하며, 분기 말 예산 잉여를 슬러시 펀드 조성으로 전환하고 교육/교육 예산을 개인 선물 또는 식사에 사용하며, 사외펀드에 비즈니스 여행 비용(예: 비즈니스 클래스 항공편)을 청구함
- ACFE: Expense Reimbursement Fraud (Budget Misuse, Cross-Charging)
- COSO: CA-03-01 승인 통제, CA-03-02 검증·조정, CA-03-06 독립 검토
- 탐지 기법(SQL 형태, 원본 분류): 임계 초과 — 절대 임계 초과 `WHERE col > fixed_threshold`, 통계적 임계 초과 `WHERE ABS(col-avg)/std > 2`, 비율 임계 초과 `WHERE col_a/col_b > ratio`, 누적 임계 초과 `WHERE SUM(col) OVER (...) > limit`, 극단값 탐지 `WHERE col >= PERCENTILE(0.99)`, 범위 상한 초과 `WHERE col > logical_max`; 누락·부재 — 필수 필드 NULL `WHERE required_col IS NULL`, 검증 로그 부재 `LEFT JOIN audit WHERE id IS NULL`, 증빙 파일 부재 `WHERE attachment IS NULL`, 역조건 존재 `WHERE cancel='Y' AND amount > 0`
- SQL 대입: 가능

## 수법

- 프로젝트 A 예산 고갈 시 프로젝트 A 비용을 프로젝트 B에 청구
- 남은 프로모션 이벤트 예산으로 개인 물품 구매
- 분기 말 예산 잉여를 슬러시 펀드 조성으로 전환
- 교육/교육 예산을 개인 선물 또는 식사에 사용
- 사외펀드에 비즈니스 여행 비용(예: 비즈니스 클래스 항공편) 청구

## 탐지 방법

- 예산 사용 속도 모니터링 — 비정상적인 기간 말 지출 플래그
- 비용 카테고리를 실제 예산 할당과 교차 참조
- 입력 지점에서 필수 비용 센터 검증 강제
- 관련 비용 센터 간 예산 이체의 반복 패턴 감지
- 카테고리별 규범을 초과하는 비용에 대한 예외 알림 구현

## 질의 골격 (원본)

- SQL: `WHERE col_a/col_b > ratio`
- SPARQL(참고, 이 환경에는 KG 가 없다): `?s dpsp:num ?n . ?s dpsp:den ?d . FILTER(?n/?d > 0.20)`
