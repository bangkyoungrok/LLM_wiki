# P-008 시스템 제어 우회

- 위험 구분: **부정(고의)** — 일부러 규정·통제를 어기거나 숨긴 행위다. 예외 조건에 고의성 신호를 넣는다(`wiki/patterns/index.md` 2절).
- 설명: 시스템 간 간극(통합 부재, 수동 우회, 검증 누락)을 악용하여 무단 작업 수행. 서로 통합되지 않은 시스템 간 데이터 조작(예: 판매 vs 정산)을 하고, 수동 PO 생성으로 잘못된 단가를 입력하며, 우회 통한 시스템 제어 우회(예: Return PO 남용)를 하고 전자상거래 시스템의 누락된 번들-반환 검증을 악용하며, 가격 합의를 위해 시스템 기록 대신 이메일 또는 구두 통신을 사용함
- ACFE: Cash Disbursements Fraud (Return PO Abuse, System Control Bypass)
- COSO: CA-01-01 활동 통제 설계, CA-03-01 승인 통제, CA-03-02 검증·조정
- 탐지 기법(SQL 형태, 원본 분류): 값 불일치 — 필드간 값 불일치 `WHERE col_a != col_b`, 테이블간 조인 불일치 `JOIN ... WHERE a.col != b.col`, 논리적 관계 위반 `WHERE col_a < col_b (A≥B여야 함)`, 참조 무결성 위반 `LEFT JOIN ... WHERE ref IS NULL`; 시간·순서 — 선후 순서 위반 `WHERE event_a_date > event_b_date`, 기간 역전 `WHERE start_date > end_date`, 비정상 단축 `WHERE (date_b - date_a) < min`, 비정상 지연 `WHERE (date_b - date_a) > max`, 순서 위반 `WHERE sequence != expected`, 동기화 역전 `WHERE sys_a.time > sys_b.time`; 누락·부재 — 필수 필드 NULL `WHERE required_col IS NULL`, 검증 로그 부재 `LEFT JOIN audit WHERE id IS NULL`, 증빙 파일 부재 `WHERE attachment IS NULL`, 역조건 존재 `WHERE cancel='Y' AND amount > 0`
- SQL 대입: 가능

## 수법

- 서로 통합되지 않은 시스템 간 데이터 조작 (예: 판매 vs 정산)
- 수동 PO 생성으로 잘못된 단가 입력
- 우회 통한 시스템 제어 우회 (예: Return PO 남용)
- 전자상거래 시스템의 누락된 번들-반환 검증 악용
- 가격 합의를 위해 시스템 기록 대신 이메일 또는 구두 통신 사용

## 탐지 방법

- 수동 오버라이드 및 오프 시스템 거래에 대한 감사 추적 분석
- 통합 시스템 간 데이터 불일치 조정
- 소급 가격/주문 변경 모니터링
- 비표준 워크플로우를 통해 처리된 거래 플래그
- 판매, 정산 및 지급 모듈 간 시스템 통합 확인 구현

## 질의 골격 (원본)

- SQL: `WHERE cancel='Y' AND amount > 0`
- SPARQL(참고, 이 환경에는 KG 가 없다): `?s a dpsc:ReturnPO . ?s dpsp:cancelFlag ?f . ?s dpsp:amount ?amt . FILTER(?f = 'Y' && ?amt > 0)`

## 대입 예시: 승인 기준 아래 할인 반복

- 대상 업무 흐름: 수주 또는 청구의 할인 적용
- 모집단: 기간 안의 할인 적용 건 전체
- 예외 조건: 할인율이 승인 기준 바로 아래(기준의 95% 이상, 기준 미만)인 건
- 정상 업무 제외: 정책 할인처럼 승인 대상이 아닌 할인(구분 코드가 있으면)
- 기준 날짜: 수주 날짜 또는 청구 날짜
- 이름 규칙: 「<기간> 할인 중 승인 기준 바로 아래 할인율이 적용된 건」
- 쉬운 설명 문장: 승인을 받지 않으려고 기준 바로 아래로 할인한 건을 찾는다
- 조사할 증빙: 할인 품의서, 가격 결정 근거, 담당자별 할인 내역
