# P-001 인센티브 조작

- 위험 구분: **부정(고의)** — 일부러 규정·통제를 어기거나 숨긴 행위다. 예외 조건에 고의성 신호를 넣는다(`wiki/patterns/index.md` 2절).
- 설명: 회사로부터 부정적인 인센티브 지급을 유발하기 위해 판매 실적 데이터(Sell-In / Sell-Thru)를 조작하는 행위. 대리점에 가짜 판매 수치 입력을 지시하거나, 시스템에서 가짜 Sell-In(S/I) 또는 Sell-Thru(S/O) 프로모션을 생성하며, 실제 출고량을 초과하는 계약 수량을 부풀리고 프로모션 간 누적 수량 검증을 부재시킴
- ACFE: Revenue Recognition Fraud, Rebate Fraud
- COSO: CA-03-01 승인 통제, CA-03-02 검증·조정, CA-03-05 책임 분리
- 탐지 기법(SQL 형태, 원본 분류): 값 불일치 — 필드간 값 불일치 `WHERE col_a != col_b`, 테이블간 조인 불일치 `JOIN ... WHERE a.col != b.col`, 논리적 관계 위반 `WHERE col_a < col_b (A≥B여야 함)`, 참조 무결성 위반 `LEFT JOIN ... WHERE ref IS NULL`; 임계 초과 — 절대 임계 초과 `WHERE col > fixed_threshold`, 통계적 임계 초과 `WHERE ABS(col-avg)/std > 2`, 비율 임계 초과 `WHERE col_a/col_b > ratio`, 누적 임계 초과 `WHERE SUM(col) OVER (...) > limit`, 극단값 탐지 `WHERE col >= PERCENTILE(0.99)`, 범위 상한 초과 `WHERE col > logical_max`; 추세·분포 — 지속 방향성 변화 `WHERE col > LAG(col) > LAG(col,2)`, 급증/급감 `WHERE ABS(col-LAG(col))/LAG(col) > 0.5`, 분포 편차 `GROUP BY grp HAVING COUNT > threshold`, 집중도 이상 `WHERE GINI(col) > 0.5`, 역추세 `WHERE CORR(col_a, col_b) < -0.5`
- SQL 대입: 가능

## 수법

- 판촉 직원 또는 대리점에 가짜 판매 수치 입력 지시
- 시스템에서 가짜 Sell-In(S/I) 또는 Sell-Thru(S/O) 프로모션 생성
- 실제 출고량을 초과하는 계약 수량 부풀리기
- 여러 프로모션에 걸쳐 누적 수량 검증 부재

## 탐지 방법

- 인센티브 클레임을 실제 공급/출고 수량과 교차 참조
- 대리인별 누적 인센티브 총액이 공급 한도를 초과하는 경우 플래그
- 인센티브 계산 시스템의 수동 오버라이드 모니터링
- 해당 소매 판매 없이 동일한 모델에 대한 반복 프로모션 생성 감지

## 질의 골격 (원본)

- SQL: `WHERE col > fixed_threshold`
- SPARQL(참고, 이 환경에는 KG 가 없다): `?s dpsp:amount ?amt . FILTER(?amt > 5000000)`

## OKF 대입 힌트 (자동 생성)

- 후보 도메인: [영업마케팅 마케팅비](okf/domains/mkt-exp.md), [영업마케팅 매출](okf/domains/sales.md)
- 관련 기존 시나리오([목록](okf/references/scenarios.md)): 셀인 대비 셀아웃 인센티브 지급수량 과다(SP_SA_SSA2307001), 셀아웃 실적 정산Level 임의변경(SP_SA_SSA2004001), 허위B2B를 통한 인센티브 부당수령(SP_SA_SSA2304002). 신규 시나리오는 이 탐지 조건과 달라야 한다.

## 대입 예시: 실적 미달 대상 지급

- 대상 업무 흐름: 판촉 약정 → 판촉 집행 또는 지급 → 실적
- 모집단: 기간 안의 판촉 지급 전체
- 예외 조건: 지급 대상의 실적이 약정의 지급 기준에 못 미치는 건, 또는 약정 금액을 넘는 지급
- 정상 업무 제외: 약정 변경 승인이 있는 지급(변경 기록이 있으면)
- 기준 날짜: 지급 날짜
- 이름 규칙: 「<기간> 판촉 지급 중 실적 기준 미달 대상에 지급된 건」
- 쉬운 설명 문장: 약정한 실적을 채우지 못한 거래처에 판촉비가 나간 건을 찾는다
- 조사할 증빙: 판촉 약정서, 실적 집계표, 지급 품의서
