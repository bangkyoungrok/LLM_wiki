# P-022 부품 대체

- 위험 구분: **부정(고의)** — 일부러 규정·통제를 어기거나 숨긴 행위다. 예외 조건에 고의성 신호를 넣는다(`wiki/patterns/index.md` 2절).
- 설명: 저가 또는 양산 외 부품을 정품 부품으로 속여 사용하거나, 정품 부품을 가짜로 교체하여 차액 착복. 비정품 또는 저가 부품을 정품으로 속여 사용하고, 부품 추적 기록을 위조하여 품질과 비용을 이중으로 착복함
- ACFE: Counterfeit Parts (1-2)
- COSO: CA-03-02 검증·조정, CA-03-05 책임 분리, CA-04-05 응용 통제
- 탐지 기법(SQL 형태, 원본 분류): 값 불일치 — 필드간 값 불일치 `WHERE col_a != col_b`
- SQL 대입: 도메인 없음

## 수법

- 저가 부품을 정품으로 속여 사용
- 정품 부품을 가짜로 교체하여 차액 착복
- 비정품 부품을 정품으로 속여 사용
- 부품 추적 기록 위조

## 탐지 방법

- 사용된 부품과 명세된 부품 간 일련번호 교차 검증
- 부품 구매 기록과 실제 사용량 간 불일치 분석
- 인증된 부품 공급업체 외 구매 건수 모니터링
- 반품 부품과 교체 부품 간 매칭 검증

## 질의 골격 (원본)

- SQL: `WHERE col_a != col_b`
- SPARQL(참고, 이 환경에는 KG 가 없다): `?s dpsp:colA ?a . ?s dpsp:colB ?b . FILTER(?a != ?b)`

## OKF 대입 힌트 (자동 생성)

- 후보 도메인: 없음(OKF 도메인 11종에 해당 업무가 없다)
- 주의: 부품 추적 테이블이 OKF 도메인에 없다. 목차에서 찾지 못하면 만들지 않은 후보로 둔다.

## 조합 단서 (자동 생성)

- SQL 대입이 「도메인 없음」인 패턴이라 조합에 넣지 않는다.
