# P-004 영수증/송장 위조 및 중복 청구

- 위험 구분: **부정(고의)** — 일부러 규정·통제를 어기거나 숨긴 행위다. 예외 조건에 고의성 신호를 넣는다(`wiki/patterns/index.md` 2절).
- 설명: 발생하지 않았거나 이미 지불된 비용을 청구하기 위해 영수증과 송장을 변조, 위조 또는 재사용. 동일한 영수증/송장을 여러 클레임에 제출하고, 영수증 금액 또는 날짜를 변조하며, 레스토랑 또는 벤더와 공모하여 부풀린 가짜 영수증을 발행하고 개인 구매 영수증을 업무 비용 청구로 사용하며, 판촉 직원 출근 기록을 위조하여 급여 청구함
- ACFE: Expense Reimbursement Fraud (Forged Receipts, Duplicate Invoices), Vendor Overbilling, Technical Service Overbilling
- COSO: CA-03-01 승인 통제, CA-03-02 검증·조정, CA-03-06 독립 검토
- 탐지 기법(SQL 형태, 원본 분류): 중복·동일인 — 식별자 중복 `GROUP BY id HAVING COUNT(*) > 1`, 연락처 중복 `GROUP BY acct_no HAVING COUNT(*) > 1`, 증빙 중복 `GROUP BY invoice_no HAVING COUNT(*) > 1`, 역할 중복 `WHERE requester = approver`, 교차 엔티티 일치 `WHERE a.col = b.col`, 완전 중복 `WHERE EXISTS (SELECT 1 FROM t2 ...)`; 형식·값 이상 — 형식 불일치 `WHERE col NOT REGEXP 'pattern'`, 논리 범위 위반 `WHERE col < min OR col > max`, 변경값 무의미 `WHERE new = old OR new = 0`, 인코딩/특수문자 `WHERE col LIKE '%invalid%'`
- SQL 대입: 가능

## 수법

- 동일한 영수증/송장을 여러 클레임에 제출
- 영수증 금액 또는 날짜 변조
- 레스토랑 또는 벤더와 공모하여 부풀린 가짜 영수증 발행
- 개인 구매 영수증을 업무 비용 청구로 사용
- 판촉 직원 출근 기록 위조하여 급여 청구

## 탐지 방법

- 번호, 금액, 벤더 및 날짜로 송장 중복 제거
- 변조 감지를 위한 OCR 기반 영수증 검증
- 벤더 유형을 claimed 비용 목적과 교차 참조
- 표준 직원별 또는 이벤트별 임계값을 초과하는 클레임 플래그
- 다른 클레임 기간에 걸쳐 사용되는 순차 송장 번호 모니터링

## 질의 골격 (원본)

- SQL: `{ SELECT ?inv (COUNT(?inv) AS ?c) WHERE { ?e dpsp:hasInvoice ?inv } GROUP BY ?inv HAVING (?c > 1) }`
- SPARQL(참고, 이 환경에는 KG 가 없다): `{ SELECT ?inv (COUNT(?inv) AS ?c) WHERE { ?e dpsp:hasInvoice ?inv } GROUP BY ?inv HAVING (?c > 1) }`
