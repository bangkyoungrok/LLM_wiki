# P-015 개발 IP 및 자원 유출

- 위험 구분: **부정(고의)** — 일부러 규정·통제를 어기거나 숨긴 행위다. 예외 조건에 고의성 신호를 넣는다(`wiki/patterns/index.md` 2절).
- 설명: 연구개발 과정에서 개발 중인 제품, 설계도, 특허, 테스트 데이터를 무단 유출하거나 사적 목적에 활용. 개발 중인 제품 스펙/설계도를 외부에 유출하여 경쟁사에 제공하고, 사내판매 제품을 외부 재판매(개발자 할인 쿠폰 남용)하며, 개발 테스트용 샘플/프로토타입을 개인용 또는 외부에 전달하고, 연구비/개발비 명목의 예산을 사적 목적에 사용하며, 개발 용역 외주 시 지인/관련 업체 선정 후 과다 청구를 함
- ACFE: Intellectual Property Theft (R&D IP Misappropriation)
- COSO: CA-04-02 시스템 접근 통제, CA-04-05 응용 통제, CA-04-06 네트워크 보안
- 탐지 기법(SQL 형태, 원본 분류): 중복·동일인 — 식별자 중복 `GROUP BY id HAVING COUNT(*) > 1`, 연락처 중복 `GROUP BY acct_no HAVING COUNT(*) > 1`, 증빙 중복 `GROUP BY invoice_no HAVING COUNT(*) > 1`, 역할 중복 `WHERE requester = approver`, 교차 엔티티 일치 `WHERE a.col = b.col`, 완전 중복 `WHERE EXISTS (SELECT 1 FROM t2 ...)`; 형식·값 이상 — 형식 불일치 `WHERE col NOT REGEXP 'pattern'`, 논리 범위 위반 `WHERE col < min OR col > max`, 변경값 무의미 `WHERE new = old OR new = 0`, 인코딩/특수문자 `WHERE col LIKE '%invalid%'`
- SQL 대입: 도메인 없음

## 수법

- 개발 중인 제품 스펙/설계도를 외부에 유출하여 경쟁사에 제공
- 사내판매 제품을 외부 재판매 (개발자 할인 쿠폰 남용)
- 개발 테스트용 샘플/프로토타입을 개인용 또는 외부에 전달
- 연구비/개발비 명목의 예산을 사적 목적에 사용
- 개발 용역 외주 시 지인/관련 업체 선정 후 과다 청구

## 탐지 방법

- 사내판매/할인 구매 패턴 모니터링 (개발자별 대량 구매 플래그)
- 연구비 집행 대목과 개발 일정/성과 간 상관관계 분석
- 개발 시스템 접근 로그 분석 (비정상 시간대/대량 다운로드)
- 테스트 샘플/프로토타입의 출고 기록과 반환 기록 조정
- 개발 용역 납품물의 기술 검토 및 시장 비교 분석

## 질의 골격 (원본)

- SQL: `WHERE col NOT REGEXP 'pattern'`
- SPARQL(참고, 이 환경에는 KG 가 없다): `?s dpsp:ip ?ip . FILTER(!REGEX(?ip, '^(\d{1,3}\\.){3}\d{1,3}$'))`

## OKF 대입 힌트 (자동 생성)

- 후보 도메인: 없음(OKF 도메인 11종에 해당 업무가 없다)
- 주의: 연구개발·IP 테이블이 OKF 도메인에 없다. 목차에서 찾지 못하면 만들지 않은 후보로 둔다.

## 조합 단서 (자동 생성)

- SQL 대입이 「도메인 없음」인 패턴이라 조합에 넣지 않는다.
