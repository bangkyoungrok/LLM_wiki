# P-017 서비스 보증 및 부품 남용

- 위험 구분: **부정(고의)** — 일부러 규정·통제를 어기거나 숨긴 행위다. 예외 조건에 고의성 신호를 넣는다(`wiki/patterns/index.md` 2절).
- 설명: 애프터세일즈 서비스 시스템에서 보증 클레임을 남용하거나, 교체 부품을 유출하여 불필요한 비용 발생 또는 사적 이익 취득. 보증 기간 만료된 제품에 대해 가짜 보증 클레임을 생성하고, 교체된 불량 부품을 서비스 센터에 반환하지 않고 유출/재판매하며, 서비스 업체와 공모하여 불필요한 수리 비용 과다 청구를 하고, 반품 처리된 제품을 서비스 시스템에 등록하지 않고 무상수리 처리하며, 인증되지 대리점에 판매된 제품에 대한 보증 서비스를 제공함
- ACFE: Customer Refund Fraud (Warranty Parts Abuse, Service Cost Inflation)
- COSO: CA-03-01 승인 통제, CA-03-02 검증·조정, CA-03-05 책임 분리
- 탐지 기법(SQL 형태, 원본 분류): 임계 초과 — 절대 임계 초과 `WHERE col > fixed_threshold`, 통계적 임계 초과 `WHERE ABS(col-avg)/std > 2`, 비율 임계 초과 `WHERE col_a/col_b > ratio`, 누적 임계 초과 `WHERE SUM(col) OVER (...) > limit`, 극단값 탐지 `WHERE col >= PERCENTILE(0.99)`, 범위 상한 초과 `WHERE col > logical_max`; 누락·부재 — 필수 필드 NULL `WHERE required_col IS NULL`, 검증 로그 부재 `LEFT JOIN audit WHERE id IS NULL`, 증빙 파일 부재 `WHERE attachment IS NULL`, 역조건 존재 `WHERE cancel='Y' AND amount > 0`
- SQL 대입: 도메인 없음

## 수법

- 보증 기간 만료된 제품에 대해 가짜 보증 클레임 생성
- 교체된 불량 부품을 서비스 센터에 반환하지 않고 유출/재판매
- 서비스 업체와 공모하여 불필요한 수리 비용 과다 청구
- 반품 처리된 제품을 서비스 시스템에 등록하지 않고 무상수리 처리
- 인증되지 대리점에 판매된 제품에 대한 보증 서비스 제공

## 탐지 방법

- 보증 클레임의 제품 구매일/반품일과 보증 기간 자동 검증
- 반품 제품 일련번호와 서비스 등록 일련번호 교차 참조
- 동일 제품/고객의 반복 보증 클레임 패턴 감지
- 서비스 업체별 수리 비용/기간 벤치마크 분석
- 교체 부품 반환 의무화 및 미반환 시 청구 조정 메커니즘 구현

## 질의 골격 (원본)

- SQL: `WHERE col >= PERCENTILE(0.99)`
- SPARQL(참고, 이 환경에는 KG 가 없다): `?s dpsp:amount ?amt . { SELECT (?p99 AS ?p) WHERE { ?x dpsp:amount ?a . BIND(percentile(?a, 0.99) AS ?p) } } FILTER(?amt >= ?p)`

## OKF 대입 힌트 (자동 생성)

- 후보 도메인: 없음(OKF 도메인 11종에 해당 업무가 없다)
- 주의: 보증 부품 테이블이 OKF 도메인에 없다. 목차에서 찾지 못하면 만들지 않은 후보로 둔다.

## 조합 단서 (자동 생성)

- SQL 대입이 「도메인 없음」인 패턴이라 조합에 넣지 않는다.
