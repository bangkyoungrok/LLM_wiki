# P-021 재고 기록 조작

- 위험 구분: **부정(고의)** — 일부러 규정·통제를 어기거나 숨긴 행위다. 예외 조건에 고의성 신호를 넣는다(`wiki/patterns/index.md` 2절).
- 설명: 재고 실사와 시스템 기록 간 불일치를 은폐하기 위해 재고 가치 부풀리기, 폐기 기록 누락, 재고 이동 기록 위조. 실제 재고보다 높은 수량을 시스템에 기록하고, 폐기 처리해야 할 제품을 시스템에서 누락시켜 재고 불일치를 생성하며, 재고 이동 기록을 위조하여 실물을 은폐함
- ACFE: Inventory Fraud (1-2)
- COSO: CA-03-02 검증·조정, CA-03-04 실적을행 비교, CA-03-06 독립 검토
- 탐지 기법(SQL 형태, 원본 분류): 임계 초과 — 통계적 임계 초과 `WHERE ABS(col-avg)/std > 2`
- SQL 대입: 가능

## 수법

- 재고 가치 부풀리기 (실제보다 높은 가치 기록)
- 폐기 기록 누락으로 재고 불일치 은폐
- 재고 이동 기록 위조
- 품질 데이터 조작으로 불량률 임계값 미만 플래그
- 수율 데이터 조작으로 품질 문제 은폐

## 탐지 방법

- 정기 창고 실사와 시스템 재고 간 차이 분석
- 폐기 기록과 폐기물 처리 업체 납품서 교차 검증
- 재고 이동 기록의 승인 절차 준수 여부 감사
- 원자재 투입량 대비 완제품 출고량 수지 분석

## 질의 골격 (원본)

- SQL: `WHERE ABS(col-avg)/std > 2`
- SPARQL(참고, 이 환경에는 KG 가 없다): `?s dpsp:amount ?amt . { SELECT (AVG(?a) AS ?avg) (STDDEV(?a) AS ?std) WHERE { ?x dpsp:amount ?a } } FILTER((ABS(?amt-?avg)/?std) > 2)`

## OKF 대입 힌트 (자동 생성)

- 후보 도메인: [영업마케팅 매출](okf/domains/sales.md)
- 주의: 재고 수불 테이블을 목차에서 찾지 못하면 만들지 않은 후보로 둔다.

## 조합 단서 (자동 생성)

- 등록된 조합 단서가 없다. 같은 후보 도메인의 다른 부정 패턴과 `wiki/patterns/index.md` 4절 규칙(같은 행, 집단→행, 흐름→행)으로 묶을 수 있으면 조합 후보로 쓴다. 묶을 상대가 없으면 단일 후보다.
