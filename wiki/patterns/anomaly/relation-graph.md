# 데이터 이상징후 패턴: 관계 그래프 (P-136 ~ P-141)

사람·업체·거래 사이의 관계망에서 보이는 신호. 관계 그래프(KG) 분석이 필요해 이 환경에서는 쓰지 않는다이다. 원본 패턴 정의(설명, 수법, 탐지 방법, COSO, 원본 질의 골격)와 Bottom-up 에서 쓰는 법(수준, 탐지 수단, 점검 질의 열 조건, OKF 에서 찾는 곳, 자주 묶이는 패턴)을 패턴마다 함께 적었다. 조합 규칙은 `wiki/patterns/index.md` 3절이다.

## P-136 이해관계 탐지

- **이 환경에서 쓰지 않음**: 관계 그래프 분석이 필요하고 이 환경에는 KG 가 없다. 가설에 넣지 않는다.
- 설명: 직원과 벤더 간 이해관계 관계가 감지되는 경우. 예를 들어 직원이 벤더의 소유주이거나, 가족 관계가 있을 때 그래프 기반 분석으로 탐지
- 기법 분류: P-08 관계 그래프
- ACFE: N/A (기술적 탐지 패턴)
- COSO: CE-03-02 윤리 가치 정의, CE-03-04 윤리 보고 채널
- 이 기법을 쓰는 부정 패턴(Top-down 참고): P-003 가짜 벤더 / 유령회사, P-005 제품 유출 및 무단 재판매, P-007 이해관계 충돌 / 자기거래, P-024 미공개 이해관계 충돌
- SQL 대입: 불가(그래프)
- 원본 질의 골격:
  - SQL: `불가능 (그래프 관계 분석 필요)`
  - SPARQL(참고, 이 환경에는 KG 가 없다): `?emp dpsp:isRelatedTo ?vnd`
- 수법: 직원-벤더 소유권 관계 / 가족 관계 통한 이해관계 / 투자 관계 통한 이해관계
- 탐지 방법: 그래프 기반 관계 분석 / 이해관계 선언과 벤더 데이터 교차 검증 / 관계 네트워크 시각화 및 분석

- 탐지 방법: 그래프 기반 자금 흐름 분석 / 임원-벤더-계좌 관계 매핑 / 비정상 자금 경로 감지
