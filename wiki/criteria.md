# 시나리오 선별 기준 (Bottom-up)

「확인」 판정을 받은 가설의 순위를 정하는 기준이다. 점수 상위 요청 건수만 시나리오로 낸다. 영향 규모는 hypothesis-worker 건수 점검의 예외 금액(HIT_AMT, 분석 기간)으로 매긴다.

| 기준 | 2점 | 1점 | 0점(시나리오에서 뺌) |
|---|---|---|---|
| 위험 연결 | 데이터 이상징후 패턴 2개 이상의 조합이고, 위험 해석 표(`wiki/risk-interpretation.md` 3절)에 직접 연결 | 간접 연결, 또는 단일 패턴 | 연결 없음 |
| 영향 규모 | 확인된 가설 가운데 예외 금액 상위 3위 안 | 예외 금액을 확인할 수 있음(4위 이하) | 금액 없음 |
| 탐지 가능성 | 비교 기준 대비 차이가 통계 도구의 범위 밖 판정이나 규칙 위반으로 확인된 신호에서 나옴 | 차이가 점검 질의의 비율 비교(판정하지 않은 단서)로만 확인됨 | 비교 기준 대비 차이 없음 |
| 조사 가능성 | 예외 건마다 확인할 증빙을 특정할 수 있음(문서번호 키가 결과에 있음) | 일부만 특정 | 특정할 수 없음 |
| 오탐 통제 | 정상 조건을 예외 질의에서 뺐고 반례 조회로 확인함 | 일부만 뺌 | 뺄 수 없음 |

합계(최대 10점)로 순위를 정한다. 같으면 매출 인식 영역, 부정 의심, 조합의 패턴 수가 많은 순, 영향 규모 순으로 앞에 둔다.

- 금액이 없는 관점(건수·비율·간격만)은 영향 규모 1점을 넘지 않는다. 통화가 다른 금액끼리는 순위를 매기지 않고 통화별로 상위 3위를 본다.
