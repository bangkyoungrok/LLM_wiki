# 감사 가치 점수 (시나리오 변형)

원본 시나리오와 「확인」·「확인(소수)」 판정을 받은 변형의 감사 가치를 매기는 기준이다. 변형은 네 기준으로, 원본은 앞의 세 기준으로 점수를 매긴다. 점수 상위 요청 개수만 시나리오로 낸다.

| 기준 | 2점 | 1점 | 0점 |
|---|---|---|---|
| 위험 연결 | 위험 해석 표(`wiki/risk-interpretation.md` 3절)의 행에 직접 연결되고, 데이터 이상징후 패턴 2개 이상의 조합 | 간접 연결, 또는 패턴 1개 | 연결 없음(변형 불가) |
| 영향 규모 | 예외 금액(HIT_AMT)이 원본·변형 가운데 가장 큼, 또는 금액이 없으면 해당 건이 가장 많음 | 예외 금액이나 건수를 확인할 수 있음 | 금액·건수 모두 없음 |
| 탐지 가능성 | 비교 기준 대비 차이가 통계 도구의 범위 밖 판정이나 규칙 위반으로 확인된 신호에서 나옴 | 차이가 비율 비교로만 확인됨 | 비교 기준 대비 차이 없음 |
| 원본과의 차이 (변형만) | 원본이 보지 못하던 대상(다른 테이블·도메인)이나 조건을 봄. 원본과 변형의 해당 건이 서로 다름 | 원본과 대상은 같고 조건만 좁거나 넓음 | 원본과 같은 건만 잡음 |

- 변형 점수는 최대 8점, 원본 점수는 최대 6점이다. 「더 감사 가치 있게」 요청이면 앞의 세 기준 합(최대 6점)을 원본과 비교해 원본보다 높은 변형만 시나리오로 낸다. 같거나 낮으면 「확인(원본보다 낫지 않음)」이다.
- 변형끼리 점수가 같으면 원본과의 차이, 부정 의심, 영향 규모 순으로 앞에 둔다.
- 통화가 다른 금액끼리는 크기를 비교하지 않고 통화별로 본다. 보고서의 「감사 가치」 줄에는 기준별 점수를 원본 → 변형으로 적는다.
