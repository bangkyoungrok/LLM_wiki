# 이전 시나리오 목록

이전에 만든 감사 시나리오의 목록이다. Top-down agent 는 이 목록을 세 가지로 쓴다.

1. **중복 회피**: 신규 시나리오는 아래 기존 시나리오와 탐지 조건이 달라야 한다. 같은 감사 포인트면 만들지 않은 후보로 두고 사유에 기존 시나리오 이름을 적는다.
2. **대입 단서**: 기존 시나리오의 참조 테이블은 그 업무에서 실제로 쓰는 테이블이다. 같은 도메인 패턴을 대입할 때 후보 테이블로 쓴다.
3. **SQL 문체 견본**: 사람이 승인한 질문-SQL 예제의 조인, 조건, DISTINCT·EXISTS 사용을 따른다. 내용이 맞다는 보장은 없으므로 조인과 조건은 OKF 문서로 다시 확인한다.

| 자료 | 내용 | 용도 |
|---|---|---|
| [기존 감사 시나리오](okf/references/scenarios.md) | 기존 추출 프로시저(SP_BQ_*, SP_SA_*)별 감사 포인트, 참조 테이블(범위 안 링크) | 중복 회피, 대입 단서 |
| [승인된 질문-SQL 예제](okf/t2s/examples/) | `okf/t2s/examples/` 폴더(파일 목록으로 조회) — 최저가 미선정, 동일 패스워드, 1위 미선정, 정산 Level 변경 등 | SQL 문체 견본 (바인드 변수 `:p_from`, 세미콜론, `BETWEEN` 날짜 범위는 `sql-query` 작성 규칙대로 리터럴·`>= AND <` 로 바꿔 쓴다) |
